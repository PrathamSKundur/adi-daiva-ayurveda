# Adi Daiva Ayurveda Clinic — Portfolio

Mobile-first single-page portfolio built with React, Tailwind CSS, Framer Motion and Lucide icons.

Quick start

1. Place the two clinic images into the `public/` folder:

   - `20260228_111659.jpg` (Hero)
   - `20260310.jpg` (Swarna drive)

2. Install dependencies and run:

```bash
npm install
npm run dev
```

App will be available at the address printed by Vite (typically http://localhost:5173).

Notes

- The project uses Google Fonts: Playfair Display (headings) and Inter (body).
- Tailwind is configured in `tailwind.config.cjs`.
- If you rename images, update the paths in `src/components/Hero.jsx` and `SwarnaSection.jsx`.
